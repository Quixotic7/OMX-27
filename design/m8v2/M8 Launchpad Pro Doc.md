# notes mode

- Rec + Play to record into phrase
- Hold Shift + Up/Down - change target instrument
- Left/right select track
- each octave is 5 notes over

Layout of notes on rows 5-8 in notes mode, x = root note, this is a 7 note scale:
x------x
---x----
------x-
--x-----

# session mode

- Snapshot - Hold Shift + Record Arm/Undo - Store
- Snapshot - Record Arm/Undo - Recall
- Shift + Left - Live Mode
- Hold Clear + click to clear slot
- Hold Dupe + click to dupe
# Edit Seq Mode
- Clear + Phrase to clear
- Dupe + Phrase to duplicate
- Hold Clip + Play to play just the single pattern
- Hold a step and use the side buttons to change velocity
- Hold step + Up Down = Octave shift
- Hold step + keyboard = lock note
- Shift + Arrow Keys = Instrument Pool
# Project Button
- In Session/clip mode pulls up load project
- In the Edit Seq mode it pulls up load instrument

# Beat Repeat
- Enter by pressing Shift + Session

use row 3 then 2 to do the loop selection

Row 1 provides toggles for which tracks you want to effect
