# ML macro LED layouts

One file per view of the ML (M8 Launchpad Pro) macro, in the OMX LED Designer format (see FORMAT.md). `OMX M8V2 aux mode layout.json` is the AUX shortcut layer shared by every view; the session and control files carry two states (HAND = L / R). These are the source of truth for the key maps; `../ML-LAYOUT-V3.md` describes the behaviour.
